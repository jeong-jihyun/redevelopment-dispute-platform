# 재개발 분쟁 도우미 (Redevelopment Legal Support Platform)

재개발·재건축 등 정비사업 분쟁을 **문제 발견 → 분쟁 분석 → 법령·판례 검색 → 대응 전략 → 서류 작성 → 증거 관리 → 후속 절차** 흐름으로 돕는 모바일 우선 웹앱(PWA)입니다.
설계 기준: 「재개발 분쟁 대응 통합 플랫폼 설계서 v0.1」, 「기본 설계서 v1.0」(2026-11-18)

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기준 데이터(사업유형 8·사업단계 12·분쟁유형 14·서류 11종·핵심 법령 21개 조문·판례 4건), 홈·통합검색·분쟁유형·법령/판례 화면, 법령 API·AI API | ✅ 1차 배포 |

## AI 법률 도우미 (2단계)

- 흐름: 질문 → 부족한 정보(사업 유형·지위·사업 단계·사전 요청 여부)를 보기 버튼으로 되물음 → 분석
- 결과 순서: 핵심 결론(분쟁 유형·근거 상태·전문가 필요성) → 사실관계·추가 확인 → 쟁점·유불리 → 법령·판례(원문 링크) → 대응 방법·위험 → 다음 행동·추천 서류
- `GEMINI_API_KEY`(무료 등급)가 있으면 AI 분석, 없거나 실패하면 기본(규칙) 분석으로 자동 대체
- AI가 앱에 없는 법령·판례·서류를 인용하면 서버와 화면에서 두 번 걸러 제외하고 "제외됨" 표시
- 주민등록번호·휴대폰 번호는 저장·분석 전에 가림, 상담 기록은 기기 내부에만 저장(삭제 가능)

## 디자인 시스템

「도시정비 분쟁지원 플랫폼 · UI Design System v1.0」(`docs/design-system-v1.0.html`) 기준
- 색·간격·모서리 토큰: `src/app/globals.css` (@theme)
- 공통 컴포넌트(버튼·배지·알림·단계·법률 근거 카드·사이드바): `src/components/ui.tsx`
- 반응형: 폰(0–700px) 하단 탭 · 태블릿(701–980px) 축소 사이드바 · PC(981px+) 고정 사이드바·2열
- 법률 근거 카드: 출처·적용 기준·시행일/연혁·조회일 메타데이터, 원문 보기·인용 복사

## 화면 (화면 ID)

- `/` 메인 홈 (HOM-001) · `/search` 검색 결과 (HOM-002)
- `/disputes`, `/disputes/[id]` 분쟁 유형 검색·상세
- `/laws` 법령·판례·행정심판 재결례·자치법규 (LAW-001~004)
- `/ai` AI 상담 (AI-001/002) · `/docs` 서류 작성 (DOC-001~003) · `/cases` 내 사건 (CAS-001~005) · `/my` 마이페이지

## 기술 구성 (모두 무료)

- Next.js 15 (App Router) + TypeScript + Tailwind CSS 4, PWA 매니페스트
- 데이터 저장: 기기 내부(localStorage, 증거 원본은 IndexedDB) — 서버 회원·권한은 다음 단계
- 법령·판례 실시간 검색: 국가법령정보 공동활용 Open API (무료, `LAW_OC`)
- AI 분석: Google AI Studio Gemini 무료 등급 (`GEMINI_API_KEY`), 키가 없으면 규칙 기반 분석으로 동작
- 배포: Vercel

## 환경 변수 (선택)

| 이름 | 설명 |
|---|---|
| `LAW_OC` | open.law.go.kr 에서 신청한 OC(이메일 ID). 없으면 공식 사이트 바로가기로 대체 |
| `GEMINI_API_KEY` | Google AI Studio 무료 키. 없으면 규칙 기반 분석 |

## 원칙

- 법령·판례는 공식 출처 원문 링크를 함께 표시하고, 요약은 쉽게 풀어 쓴 것임을 명시
- AI는 제공된 근거 목록의 id만 인용, 서버에서 다시 검증해 목록에 없는 인용은 제거
- 주민등록번호·전화번호는 AI 전달·문서 생성 전에 마스킹
- 법률정보 제공 서비스이며 변호사의 법률의견을 대체하지 않음
