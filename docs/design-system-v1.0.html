디자인 원칙

모든 화면과 컴포넌트에 공통 적용하는 기준

공공 서비스에 적합한 안정감

네이비와 블루를 중심으로 전문성과 안정성을 전달합니다. 과도한 장식과 강한 채도를 제한합니다.

정보 우선 계층 구조

핵심 결론, 법적 근거, 세부 설명, 다음 행동 순으로 정보를 배치합니다.

상태의 명확한 구분

진행·검토·주의·완료 상태를 색상과 텍스트로 함께 표현합니다.

모바일 우선 접근성

작은 화면에서도 주요 행동을 쉽게 찾고 터치할 수 있도록 구성합니다.
